# Music Showcase · 節目單蒐集

單一 HTML 檔案的開放式「演出曲目填寫」表單，中／英／雙語，支援雲端即時同步（Google Sheet，零成本）。

> 與「志工認領網站」分開，是獨立的網站。各家庭自己上網填寫孩子的演出曲目。

## 規格

- **一首一筆**：同一孩子多首曲子就多填幾筆。
- **欄位**：孩子姓名、曲目名稱、作曲家（必填）、樂器（下拉 + 其他）、曲目長度（分/秒下拉）、是否有伴奏、伴奏幾人（1–6）、伴奏樂器、伴奏老師名字、聯絡方式、備註。
- **公開展示**：所有人能看到已收曲目清單（姓名、曲目、作曲家、樂器、長度、伴奏）；**聯絡方式與備註不公開**，只有主辦在 Google Sheet 看得到。
- **可編輯**：每筆有「編輯」按鈕，開放式（誰都能改）；編輯時聯絡方式／備註保留舊值。

## 部署（與志工網站相同流程）

1. 開 <https://sheet.new> 建一份試算表。
2. 擴充功能 → Apps Script → 貼上 `apps-script/Code.gs` → 儲存。
3. 部署 → 新增部署作業 → 網頁應用程式 → 執行身分「我」、存取權「任何人」→ 部署。
4. 複製 `/exec` 網址，填進 `index.html` 的 `CONFIG.API_URL`。
5. 把 `index.html` 上傳到 GitHub Pages 等靜態託管。

## 本機測試

```bash
python3 mock_server.py 8899
```

- 本機模式 → <http://localhost:8899/>
- 雲端模式 → <http://localhost:8899/cloud.html>
